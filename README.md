# Cybersecurity Controls & Risk Assessment Project

## Project Overview

This project focused on reviewing project controls, identifying control gaps, assessing associated risks, and providing recommendations for improvement.

## Key Activities

- Conducted a retrospective review of the project.
- Identified issues and areas where controls were not effective.
- Researched the identified risks and their potential impact.
- Assessed risks based on their severity: High, Medium, and Low.
- Reviewed existing controls and identified areas for improvement.
- Provided recommendations to reduce identified risks and strengthen project controls.

## Skills Demonstrated

- Risk Assessment
- Control Evaluation
- Risk Identification
- Research & Analysis
- Problem Solving
- Security & Project Controls
- Report Writing

## Outcome

The assessment provided a structured view of the identified risks and control weaknesses, along with practical recommendations to improve the project's overall control environment.
